# 최신 중간발표 PPT

[콘텐츠 3종과 로컬 구현을 반영한 PPT](ESEL_중간발표.pptx)

- 기존 11장 구성과 디자인을 유지했습니다.
- 9번 슬라이드에 일·주·월 표지 특집, 주간 드레스코드, 같은 옷·다른 코디를 정리했습니다.
- 발표자 노트에 각 콘텐츠의 설명과 현재 구현 범위를 적었습니다.
- 현재는 서버 없이 휴대폰 안에서 저장하고 실행하는 단계입니다. 다른 휴대폰과의 공유·동기화와 서버 운영자의 공식 선정은 아직 구현하지 않았습니다.
- 월간 스타일 결산이나 연간 베스트·공개 인기 순위는 추가하지 않았습니다.

앱 실행과 확인 방법은 [기간 특집 안내](../flutter/PERIOD_COLLECTIONS.md)를 참고하세요.

## 파일 갱신 방법

공용 발표 파일은 `ESEL_중간발표.pptx` 하나로 유지합니다. 내용을 수정하면 이 파일을 교체하고 같은 경로로 커밋합니다. 날짜·버전 번호·최종본 등의 이름을 붙인 PPT를 추가로 쌓지 않습니다. 이전 내용은 Git 커밋 이력에서 확인합니다.
