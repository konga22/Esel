# 미니 잡지형 SNS 리서치 (2026-10-03)

Esel의 표지 SNS·개인 미니 잡지 방향을 뒷받침하거나 반박할 근거를 모은 웹 조사 보고서 세 편이다. 보조 에이전트가 웹 검색으로 작성했고, 사람이 출처를 다시 확인하지 않았다. 각 보고서가 "확인 못 함", "출처 약함", "2차 확인", "추론"으로 표시한 항목은 그대로 믿지 말고 인용 전에 원문을 확인한다.

| 파일 | 다루는 질문 |
| --- | --- |
| [00-full-report-with-proposals](00-full-report-with-proposals.md) | 별도 채팅(Opus 5.5)이 쓴 통합 보고서. 네 질문 전체와 기능 제안 15개, 출처 140개 |
| [01-magazine-elements-and-precedents](01-magazine-elements-and-precedents.md) | 잡지 한 호의 요소 중 SNS 게시물로 옮길 가치가 있는 것, 비슷한 디지털 서비스의 성공·실패 |
| [02-magazine-market](02-magazine-market.md) | 인쇄·디지털 잡지 시장 추세, 패션 잡지의 매출 전환, 한국 시장, 독립 잡지 |
| [03-retention-psychology](03-retention-psychology.md) | 계속 쓰게 만드는 심리 작용의 근거와 Esel에서의 위험, 규제 동향 |

00은 01~03과 따로 조사한 것이라 같은 사실의 수치가 다른 곳이 있다(예: BeReal의 회사 주장 일 이용자 2,000만 대 2,500만, Apple News+ 수록 매체 300종 대 400개). 인용 전에 원문으로 맞춘다. 기능 제안은 00의 4절에만 있다. 모든 보고서의 "Esel에서의 위험", "시사점", "제안"은 조사자의 추론이며 제품 결정이 아니다. 제품 기준은 [앱 하네스](../../ESEL_HARNESS.md)가 정한다.
