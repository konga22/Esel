# 콘텐츠 검증·목업 점검

## 검증 기준과 결과 (2026-10-18)

주간 드레스코드·같은 옷, 다른 코디·일·주·월 표지 특집의 **로컬 시연 동작**과 표지 편집·저장 보완을 대상으로 한다. 서버 기능 전체의 완료를 의미하지 않는다. 실행과 데이터 경계는 [로컬 실행 안내](LOCAL_CONTENTS.md)와 [기간 특집 안내](PERIOD_COLLECTIONS.md)를 따른다.

| 검사 | 결과 | 범위 |
|---|---|---|
| Flutter analyze | 경고·정보 없음 | Flutter 3.44.0 / Dart 3.12.0 |
| Flutter 테스트 | 170개 통과 | 도메인·저장·위젯·시연 흐름 |
| 기존 제품 규칙 테스트 | 60개 통과 | 공개·발행·복원 등 기존 규칙 |
| 하네스 정합성 | 통과 | 기능 목록·참조 파일·생성 파일 |
| Android x64 debug mock APK | 빌드 성공 | 서버 없이 실행하는 시연 모드 |

기간 이동·선정 이유 저장/수정·해제, 주간 참여와 오늘 호 연결, 같은 옷 비교, 공개 필터, 계정별 저장·재조회, 삭제 후 중복 발행 방지, 옛 version 1 JSON 호환을 검사했다. 저장 실패 시 롤백과 재시도, 서울 자정·기간 경계도 자동 검사 대상이다.

작은 화면·글자 200%·빈 화면·실패·뒤로가기는 관련 위젯 테스트로 확인했다. 모든 실기기에서 앱 전체 레이아웃을 검수했다는 뜻은 아니다. 저장 복원은 파일 저장소를 닫고 새 LocalLibrary로 다시 읽는 검사와 메모리 저장소 화면 테스트를 구분한다.

## 직접 확인한 범위와 미검증 범위

- Android 테스트 에뮬레이터에서 이메일 가입·앨범 선택·창간호 발행·내 잡지·오늘 호의 주간 참여 연결, 앱 종료 후 재로그인·기록 복원을 확인했다. 이후 확장한 특집 화면과 모든 얼굴 연출 조합의 최종 수동 검수는 미완료다.
- 얼굴 위치 지정 후 물감 적용과 목 아래 자르기를 일부 직접 확인했다. 이후 다중 선택·제호 크기·원본 위치 지정에서 효과 복귀 보완은 자동 위젯 테스트로 확인했다. 이전 화면 이미지는 최신 동작의 증거로 사용하지 않는다.
- 목업 화면 등록부는 CH1·CL1을 포함해 56개다. 생성 캡처는 구성 참고 자료이며 Flutter 실행 화면의 증거가 아니다. 목업 전체를 직접 눌러본 검수는 미완료다.
- macOS·iOS·물리 휴대폰, 전체 사진 권한 조합, 실제 OAuth·Docker·DB·서버 API·원격 동기화는 미검증이다. 새 특집 화면은 실기기에서 추가 확인해야 한다.

## 문서·자료 정리 검증 (2026-10-18)

리뷰 후속 변경은 문서·JSON 형식·이전 증거 이미지 정리만 포함한다. features.json은 정리 전후 파싱 결과가 동일함을 확인하고 개발 문서를 재생성했다. 하네스 검사, 제품 규칙 테스트 60개, 디자인 생성 및 목업 빌드, diff 공백 검사를 다시 통과했다. 이 후속 변경에서 Flutter 테스트·APK 빌드·기기 화면 검수를 새로 실행하지 않았으며, 위 170개 결과는 기능 구현 시 수행한 검사 결과다.

## 얼굴 연출 P15 팀 결정 반영 (2026-10-18)

창간 J6와 오늘 호 C6에 단일 자르기(그대로·제호 뒤로·목 아래)와 별도 물감 토글을 적용했다. 목 아래는 물감을 자동 해제하고 버튼을 비활성화한다. 제호 뒤로+물감은 허용한다. 다른 자르기로 돌아갈 때 물감을 자동 복원하지 않는다. 이전 중복 선택 저장본은 삭제하지 않고 목 아래 우선으로 읽으며 이때 물감을 제외한다. 잡지 이름·얼굴 크기와 위치 편집은 유지한다.

전체 Flutter 테스트 **171개 통과**: 16가지 이전 조합과 각 버튼 전환, 저장·재조회 시 크기 유지, 창간→가입→발행 전달, 편집 화면의 물감 비활성화와 미리보기 복귀를 포함한다. 변경으로 늘어난 화면 높이에 맞춰 기존 스크롤 테스트는 버튼을 화면 안으로 이동한 후 누르도록 보완했다. Flutter 정적 분석·하네스·규칙 60개와 Android x64 debug mock APK 빌드도 통과했다. 기존 image_picker_android의 향후 Kotlin 호환 경고는 남아 있다. 이번 변경의 실기기·에뮬레이터 직접 조작과 macOS/iOS 검수는 미검증이다. 비공개 디자인 캔버스와 기존 캡처 갱신은 별도 작업이다.

## 핵심 서버 API 연결 검증 (2026-10-18)

기존 로컬 콘텐츠 검증과 별도로, 최신 main의 핵심 서버 API를 Flutter 서버 모드에 연결했다. 상세 범위·실행·재현 절차는 [핵심 API 안내](CORE_API_CONNECTION.md)를 따른다.

| 검사 | 결과 | 확인한 범위 |
|---|---|---|
| Flutter 정적 분석 | 문제 없음 | 새 소스·화면·테스트 포함 |
| 전체 Flutter 테스트 | 191개 통과, 실제 연결 1개는 기본 실행에서 건너뜀 | 기존 로컬 기능과 새 HTTP 계약·위젯 검사 |
| 명시적 실제 Docker 연결 검사 | 1개 통과 | 별도 실행. 로그인·사인 확인/프로필 생성·색 선택·표지/한 줄 조회·반응·구독·내 반응·복원·재로그인 |
| API 컨테이너 재시작 후 같은 계정 검사 | 통과 | 실제 DB의 반응·구독·색 기록 재조회. 기존 DB·볼륨 삭제 없음 |
| 서버 모드 Android x64 debug APK | 빌드 성공 | 기존 image_picker_android의 향후 Kotlin 호환 경고는 남음 |
| 제품 규칙 / 서버 하네스 테스트 | 60개 / 24개 통과 | 기존 공개·발행 규칙 및 검사 도구 |
| 하네스 / 서버 계약 정합성 | 통과 | 제품 계약 19개·기능 25개·목업 56개 유지 |
| 디자인 생성 / 목업 빌드 | 통과 | 디자인 캔버스·캡처 자체 변경 없음 |

실제 Docker 검사는 새 테스트 계정과 조회용 메타데이터 표지를 추가해서 진행했다. 업로드·새 표지 발행 API를 검증한 것은 아니다. 본인에게만 허용된 반응 수가 다른 계정에서 403으로 거절되는 것도 확인했다. 팀원 재현용 준비 도구를 사용한 별도 새 계정에서도 연결 검사를 통과했다.

자동 위젯 검사에서는 후보 선택 실패 후 이전 후보를 숨기고 재시도하는 동작, 발행 후 색 변경 버튼 비활성화, 공개 표지의 반응 숫자 비노출, 404 상세에서 조작 제거, 댓글 실패 시 입력 유지, cursor 추가 조회, 좁은 화면·글자 200%의 색 기록 화면을 확인했다. 실제 서버 화면을 에뮬레이터나 휴대폰에서 눌러본 검수·녹화·macOS/iOS 실행은 하지 않았다. 해당 범위는 미검증이다.

사진 URL·업로드·새 서버 발행, 추천 피드·팔레트 추천/검색, 전역 구조·화면 단어 정리(DEV-25), 착용 정보(DEV-24), 투표 전시는 이번 작업에서 미구현/제외다. 과거 날짜 후보 조회 API가 없어 복원창은 12색 선택 후 서버가 후보 여부를 검사한다. 기능 목록은 전체 기능 완료로 바꾸지 않았다.

PR 준비 중 추가 병합된 디자인 개편 #15도 작업 브랜치에 반영했다. 디자인 개편의 Flutter 이식이나 DEV-25를 이 작업으로 완료 처리하지 않는다. 최신 하네스·생성 문서·기존 제품 규칙 검사도 다시 통과했다.
